AUCTION ELEVEN v0.2 REPLACEMENT FILES

1. Back up your old Auction Eleven project.
2. Extract this ZIP inside the root of the old project.
3. Allow it to replace files with the same paths.
4. Delete the old apps/web/dist folder first if your extractor does not remove old hashed files.
5. Run:

   npm install
   npm run typecheck
   npm test
   npm run build
   npm run dev

The real player photos are loaded through the server from Wikimedia Commons while the game is online. They are not unlicensed image files bundled inside this ZIP.
